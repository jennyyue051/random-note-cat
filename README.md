# Random Note Draw

随机抽卡：点击侧边栏的骰子图标，或执行命令「抽一张随机笔记」，弹出像素风抽卡界面，随机抽出一篇笔记。

## 功能

- 侧边栏骰子图标 + 命令面板两种入口
- **像素风抽卡弹窗**：Monocraft 字体 + 翻卡动画；每次抽卡从 20 只像素小猫中随机抽出一只（橘猫/黑白/纯白/三花/灰/蓝灰等，避免连续同款），小猫为抠图素材内嵌在插件里
- **自动打卡**：每次抽到笔记自动追加到记录文件（默认 `Random Notes/打卡记录.md`，可配置路径与开关）
- 设置项：
  - **排除的文件夹**：逗号分隔的路径，其中的笔记不会被抽到
  - **只抽每日笔记**：只抽文件名以 `YYYY-MM-DD` 开头的笔记
  - **避免连续抽到同一篇**：默认开启
  - **在新标签页打开**：默认在当前标签页打开
  - **抽卡打卡记录** / **记录文件路径**

## 开发

```bash
npm install
npm run dev   # 开发模式，监听改动自动编译
npm run build # 生产构建
```

## 安装（手动）

将 `main.js`、`manifest.json`、`styles.css` 复制到 vault 的
`.obsidian/plugins/random-note-draw/` 目录，然后在 Obsidian 设置 → 社区插件中启用。
